\# Login Security Notes



\## Common Login Security Concepts



\### 1. Strong Passwords

A strong password should be long, unique, and hard to guess.



Good password habits:

\- Use at least 12 characters

\- Mix uppercase, lowercase, numbers, and symbols

\- Avoid names, birthdays, and common words

\- Do not reuse passwords across websites



\### 2. Multi-Factor Authentication



Multi-factor authentication adds another layer of protection besides just a password.



Examples:

\- Authenticator app codes

\- Security keys

\- Backup codes



\### 3. Account Lockout



Some systems temporarily lock accounts after too many failed login attempts.



This helps slow down password guessing attacks.



\### 4. Password Hashing



Websites should not store plain-text passwords.



Instead, they should store password hashes using secure methods.



\### 5. Phishing Awareness



Attackers may create fake login pages to trick users.



Always check:

\- The website URL

\- HTTPS

\- Spelling mistakes

\- Suspicious messages
