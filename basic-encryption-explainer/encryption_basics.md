\# Basic Encryption Explainer



\## What Is Encryption?



Encryption is the process of turning readable information into unreadable text so only the right person or system can read it.



\## Plaintext



Plaintext is the original readable message.



Example:



Hello



\## Ciphertext



Ciphertext is the scrambled version of the message after encryption.



Example:



Khoor



\## Key



A key is used to lock or unlock encrypted information.



Without the correct key, the message should be difficult to read.



\## Encoding vs Encryption vs Hashing



\### Encoding

Encoding changes data into another format.



It is not meant for security.



Example:

\- Base64



\### Encryption

Encryption protects data using a key.



It can be reversed if you have the correct key.



\### Hashing

Hashing turns data into a fixed-length value.



It is usually one-way and cannot be reversed.



Example:

\- SHA-256



\## Beginner Example: Caesar Cipher



The Caesar cipher shifts letters by a number.



Example:



A shifted by 3 becomes D.



This is useful for learning, but it is not secure for real protection.
